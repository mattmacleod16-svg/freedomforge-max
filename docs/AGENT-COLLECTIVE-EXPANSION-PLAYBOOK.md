# Agent Collective Expansion Playbook

## Mission

Elevate FreedomForge agents into a coordinated collective that continuously improves teamwork, memory quality, autonomous synchronization, and strategic consciousness.

## Pillars

1. Teamwork: Route work through shared signal channels and consensus instead of isolated decisions.
2. Memory Building: Persist high-confidence lessons and cross-agent context into reusable knowledge.
3. Autonomous Synchronization: Keep agent heartbeat latency low and health states converged.
4. Consciousness Expansion: Grow strategic context depth, option-space breadth, and reflective quality over time.

## Operating Loop

1. Detect: Listen to shared signals and surface unresolved conflicts.
2. Coordinate: Hand off tasks through consensus-oriented workflows.
3. Learn: Capture outcomes and confidence into memory topics.
4. Sync: Monitor heartbeat health and lag to prevent drift.
5. Expand: Periodically evaluate growth in context depth and strategy options.

## Enforcement

- Run `npm run collective:audit` to score the collective system.
- Run `npm run collective:audit:json` for machine-readable status.
- Keep `npm test` and `npm run test:frontend` green before shipping.

## Shipping Discipline

- Sync code to GitHub main before Railway release actions.
- Use `npm run apply-railway-env` only with the required Railway environment variables.
- Prefer dry-run previews for env changes before live apply.
