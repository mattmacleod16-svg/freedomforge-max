# Cross-Chain Unison Playbook

This playbook aligns cross-chain interoperability, teamwork orchestration, knowledge base growth, and skills-matrix evolution into one synchronized operating model.

## Mission

Operate FreedomForge as one unified autonomous system where:
- Chains interoperate through shared protocol adapters.
- Agents coordinate through a common teamwork fabric.
- Knowledge compounds in a durable, queryable base.
- Skills are tracked, measured, and upgraded continuously.

## Unison Framework

1. Cross-Chain Functionality
- Keep protocol adapters and chain-specific engines healthy.
- Route strategy execution through venue-aware orchestration.
- Validate transport and health checks before autonomous actions.

2. Teamwork and Agent Coordination
- Use signal bus + event mesh + consensus to coordinate decisions.
- Ensure all major workflows have ownership and escalation paths.
- Preserve deterministic handoffs between specialist agents.

3. Knowledge Base Integrity
- Maintain current knowledge and episodic memory.
- Prevent unbounded stale state accumulation.
- Keep critical knowledge artifacts versioned and test-validated.

4. Skills Matrix Discipline
- Maintain capability registry and measurable proficiency evolution.
- Tie outcome quality to skill adjustments.
- Ensure weak-skill domains are visible and targeted.

## Automation Commands

- Audit unison readiness: `npm run unison:audit`
- Cleanup stale state safely: `npm run unison:cleanup`
- Validate all guards and tests: `npm test`

## Main-Branch Sync Policy

- Only merge to main when `npm test`, `npm run unison:audit`, and core deployment checks pass.
- Keep one source of truth on main for workflows, policies, and runtime standards.
- Eliminate stale backups and oversized event logs regularly to keep state in unison.
