# 📋 FAQ

**Q: Do I need to be technical to use FreedomForge?**
A: No. The web interface at freedomforge.one lets you chat with 50+ AI models just like you'd use ChatGPT. The DeFi and trading features are for more advanced users.

**Q: Is my data safe?**
A: Yes. FreedomForge uses HMAC-SHA256 cryptographic signing, multi-layer authentication, and runs on enterprise-grade Railway infrastructure with TLS encryption.

**Q: Can I run this on my own server?**
A: Absolutely. It's open source. Clone the GitHub repo, set your environment variables, and deploy anywhere — Railway, AWS, your own hardware.

**Q: What chains does it support?**
A: EVM-compatible chains (Ethereum, Polygon, Arbitrum, etc.), Stellar, and Cosmos IBC. More chains are being added continuously.

**Q: How does the multi-model routing work?**
A: FreedomForge analyzes your query — language, task type, complexity — and automatically routes it to the best AI model. Chinese text goes to DeepSeek, code to GPT-4o or Claude, real-time questions to Grok, creative writing to Claude, and so on.

**Q: What's the $FORGE token?**
A: $FORGE is the governance token for FreedomForge. Token holders can vote on platform decisions, access premium features, and participate in DAO governance.

**Q: How can I contribute?**
A: Fork the repo, submit PRs, report issues, or just spread the word. Every contribution matters.
